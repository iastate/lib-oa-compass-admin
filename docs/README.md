# Documentation

The maintained public documentation set is:

- `PB.md` — product purpose, users, capabilities, and public/private boundary.
- `SDD.md` — frontend architecture, data flow, configuration, and external API boundary.
- `CCR.md` — canonical registry of public components, services, models, and routes.
- `openapi/oa-proxy.openapi.yaml` — authoritative external service contract.
- `../PLANS.md` — public implementation and release plan.

Behavior or interface changes must update the relevant canonical artifacts in
the same contribution. Service internals and operational records belong
outside this public documentation set.
